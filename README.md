# 📚 Python Libraries Notebooks

A collection of Google Colab notebooks covering the fundamentals of Python's most widely used data analysis and visualization libraries. This repository serves as a learning resource and reference for beginners exploring data science with Python.

## 📂 Contents

- 📘 **array.ipynb** – NumPy arrays and array operations
- 📘 **series.ipynb** – Pandas Series
- 📘 **dataframes.ipynb** – Pandas DataFrames and data manipulation
- 📘 **groupby.ipynb** – GroupBy operations and aggregation
- 📘 **concating_merging.ipynb** – Concatenating and merging DataFrames
- 📘 **date_and_time.ipynb** – Working with dates and time in Pandas
- 📘 **vectorized_strings.ipynb** – Vectorized string operations
- 📘 **matplotlib.ipynb** – Data visualization using Matplotlib
- 📘 **seaborn.ipynb** – Statistical data visualization with Seaborn

## 🛠 Libraries Used

- NumPy
- Pandas
- Matplotlib
- Seaborn

## 🎯 Purpose

This repository is intended to:
- Practice Python data analysis libraries.
- Understand core concepts through hands-on examples.
- Serve as a quick reference for commonly used functions and techniques.

## ▶️ Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/<your-username>/library_notebooks.git
   ```

2. Open the notebooks using:
   - Jupyter Notebook
   - JupyterLab
   - Google Colab

3. Install the required libraries if needed:
   ```bash
   pip install numpy pandas matplotlib seaborn
   ```
